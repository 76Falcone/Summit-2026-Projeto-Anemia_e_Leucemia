Summit 2026 | Classificação de Anemia e Leucemia com SVM

Projeto desenvolvido para o Summit 2026. Que usa Support Vector Machine (SVM) para classificar registros de hemograma (CBC) em categorias de diagnóstico, incluindo diferentes tipos de anemia, leucemia e trombocitopenia.
